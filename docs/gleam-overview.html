02 — Lifecycle

The 6-Phase Lifecycle

Every project follows a structured lifecycle, from initial discovery to deployment. Each phase has dedicated skills, quality gates, and AI-powered automation.

01
Discovery
/discover /research
Guided requirements gathering + competitive landscape analysis. Builds the foundation for everything that follows.

03

05 — Agentic Design System

Design That AI Understands

Every component ships with machine-readable metadata. AI agents don't just write code — they understand and enforce design decisions.

Design Tokens

OKLCH color system generated from a single brand hue. Typography (Inter + JetBrains Mono), 4px spacing grid, motion tokens, and personality-driven border radii.

  • OKLCH colors from brand hue
  • Semantic token layers
  • CSS custom properties
  • Motion levels (subtle/moderate/expressive)

UI Components

Button, Card, Input, Badge — each with ComponentMeta: machine-readable metadata that describes variants, states, and relationships for AI agents.

  • ComponentMeta per component
  • Variant + state matrices
  • Accessibility built in
  • AI-readable documentation

Figma Integration

Bidirectional sync via MCP. Push components to Figma, pull design updates back to code. Code Connect maps ensure parity.

  • Design-to-code via MCP
  • Code-to-design sync
  • Code Connect mappings
  • Variable/token sync

Design Governance

Automated quality gates for design consistency. The design-reviewer agent, /design-review skill, and design-system rules work together.

  • /design-review skill
  • design-reviewer agent
  • design-system rule
  • Token compliance checks

Brand Questionnaire

During project init, answer a few questions about your brand identity. Gleam generates a complete, consistent design system from your answers.

  • Primary hue (0–360)
  • Personality: professional/playful/minimal/bold
  • Motion level preference
  • Typography override options

08 — Getting Started

Up and Running in Minutes

From template to production-ready project in six steps. No boilerplate, no configuration drift, no guesswork.

1

Open the template in Claude Code

Clone or open the Gleam template project in your Claude Code workspace.

2

Run the init skill

Type /init-project to start the interactive setup — or /init-project solo-saas to use a preset.

3

Answer the questionnaire

Project name, stack selection, brand identity (primary hue, personality, motion level). Takes about 2 minutes.

4

Gleam generates your project

Full monorepo with Claude Code integration: CLAUDE.md, rules, agents, skills, hooks, design tokens, and CI/CD — all configured.

5

Start a session

Open the generated project and run /start-session. Claude loads the constitution, reads project status, and is ready to work.

6

Begin product discovery

Run /discover to start guided requirements gathering. The lifecycle begins.
